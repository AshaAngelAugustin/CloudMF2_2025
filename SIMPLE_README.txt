DATABASE CONVERTER - SIMPLE PROJECT

What it does:
- Converts SQL files between Oracle, SQL Server, and Sybase
- Upload a file, pick target database, get converted file
- Works with .sql, .txt, .csv files

How to use:
1. Open simple.html in any web browser
2. Upload your SQL file
3. Choose target database format
4. Click Convert
5. Download the result

Files included:
- simple.html (main app)
- Sample SQL files for testing
- Documentation

No installation needed - just open simple.html and start converting!
